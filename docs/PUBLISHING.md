# Публикация вручную

Интеграция с Instagram не включена. Приложение не отправляет медиа и сообщения, не обходит защиту и не модифицирует метаданные для скрытия повторов.

После монтажа переведите эксперимент в READY, выполните `bali publish queue`. Очередь создаст PENDING-записи по вариантам. `bali publish approve PUB-BALI-0001-V01` фиксирует человеческое решение. Затем опубликуйте через официальный интерфейс Instagram и зарегистрируйте результат:

```sh
bali publish record PUB-BALI-0001-V01 --external-id 'instagram-reel-id-or-url' --published-at '2026-10-26T10:00:00Z'
```

Запись без APPROVED отклоняется. Record не публикует контент: это журнал уже выполненного ручного действия. Не записывайте вымышленные external_id в рабочую базу. Автопубликации нет. `bali --dry-run publish queue` покажет будущую очередь без сохранения.
