# Ежедневный цикл

1. Активируйте `.venv`, выполните `bali today`.
2. Выберите одну hypothesis. Получите hooks, script и shoot-brief. Заполните личные факты и проверьте длительность.
3. Снимите материал. `bali footage index footage` индексирует метаданные без изменения медиа. `bali footage tag <path> --tags 'villa,morning' --location 'Bali'` добавляет ручные данные. Vision tagging пока отсутствует; расширение — отдельный обработчик записей footage.
4. Проведите эксперимент по статусам через `bali experiment status <id> <status>`.
5. Составьте variants plan, соберите props и откройте Studio. Проверяйте варианты с разным началом и смыслом, не только внешним оформлением.
6. Подтвердите публикацию, опубликуйте вручную и зарегистрируйте ссылку/ID.
7. Импортируйте накопительные метрики. `bali score`, `bali winners`, `bali evolve <winner-id>`.
8. Запишите вывод: `bali learning add BALI-0001 --text 'Наблюдение, а не причинный вывод' --confidence 0.5`.

Highest-leverage action в MVP — простая эвристика наличия сценария, не оптимизатор. Дневные очереди ограничены 10 строками. Никаких автоматических продаж или общения с гостями.
